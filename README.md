# Todo App - HTTP сервер на Go

REST API сервер для управления задачами (todos), реализованный на Go с использованием только стандартной библиотеки. Все данные хранятся в памяти без использования внешних баз данных.

## Требования

- Go 1.25.5 или выше
- Docker и Docker Compose (опционально, для контейнеризации)
- Task (опционально, для удобного управления задачами через Taskfile)

## Установка и запуск

1. Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```

2. При необходимости отредактируйте `.env` файл под свои нужды.

3. Запустите сервис:

Через Docker compose:
```bash
docker compose up -d --build
```
Через Taskfile:
```bash
task docker:up
```



## API эндпоинты

| Метод | Эндпоинт | Описание | Статусы ответа |
|-------|----------|----------|----------------|
| POST | `/todos` | Создание новой задачи | 201 Created, 400 Bad Request |
| GET | `/todos` | Получение списка задач с поддержкой параметров | 200 OK |
| GET | `/todos/{id}` | Получение задачи по идентификатору | 200 OK, 404 Not Found |
| PUT | `/todos/{id}` | Обновление задачи по идентификатору | 200 OK, 400 Bad Request, 404 Not Found |
| DELETE | `/todos/{id}` | Удаление задачи по идентификатору | 204 No Content, 404 Not Found |

### Параметры для GET /todos

Эндпоинт GET `/todos` поддерживает следующие query параметры:

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `limit` | integer | Ограничение количества возвращаемых задач | `?limit=10` |
| `offset` | integer | Смещение для пагинации | `?offset=5` |
| `sort` | string | Поле для сортировки (id, title) | `?sort=title` |
| `completed` | boolean | Фильтр по статусу выполнения | `?completed=true` |

## Выполнение требований ТЗ

### Обязательные требования

- [x] **Эндпоинты**: Все требуемые эндпоинты реализованы
  - POST /todos
  - GET /todos
  - GET /todos/{id}
  - PUT /todos/{id}
  - DELETE /todos/{id}

- [x] **Структура задачи**: Реализована со всеми требуемыми полями (также самостоятельно добавлены и другие поля)
  - ID (числовой идентификатор)
  - Title (заголовок)
  - Description (описание)
  - Completed (признак завершённости)

- [x] **Хранилище данных**: Реализовано in-memory хранилище без внешних БД
  - Используется `map[int]*models.Todo` с `sync.RWMutex` для потокобезопасности

- [x] **Валидация**: Реализована проверка заголовка
  - Заголовок не должен быть пустым
  - При ошибке валидации возвращается статус 400 Bad Request

- [x] **Обработка ошибок**: Реализована корректная обработка ошибок
  - 404 Not Found при отсутствии задачи
  - 400 Bad Request при ошибках валидации
  - 500 Internal Server Error при внутренних ошибках

- [x] **Unit-тесты**: Реализованы тесты для репозитория

- [x] **Только стандартная библиотека**: Проект использует только стандартную библиотеку Go
